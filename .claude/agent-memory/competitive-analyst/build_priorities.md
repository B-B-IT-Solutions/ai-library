Priority ranking as of May 2026 competitive analysis. Re-evaluate quarterly.

## Priority 1 — PUBLIC EXPLORE/DISCOVERY FEED (Effort: Medium)
Route: /explore. Auth-free. Curated + trending templates and collections. Category filters, search, popularity sort. This is the missing viral acquisition entry point. Without it, no organic growth loop exists. Closes the biggest gap vs. FlowGPT and PromptBase simultaneously. Also generates SEO-indexable pages per template.

## Priority 2 — IN-PLATFORM PROMPT TESTING / LIVE PREVIEW (Effort: Medium)
"Test" button on templates: fills form fields, renders full prompt, sends to LLM API (GPT-4o/Claude), shows output inline. Directly converts the typed-form-field advantage into demonstrable value. Eliminates the "buy blind" problem that is PromptBase's #1 user complaint. Directly increases purchase conversion rate.

## Priority 3 — VIRAL SHARING FOR INDIVIDUAL PROMPTS (Effort: Low)
Route: /p/prompts/{token}. Auth-free preview page with form fields + "Use this prompt" CTA + optional output preview. Extends the existing collection-sharing infrastructure to individual prompts. Each shared prompt is an acquisition funnel.

## Priority 4 — CREATOR DASHBOARD WITH ANALYTICS (Effort: Medium)
Sales volume, revenue, view-to-buy conversion per prompt, trending search insights (what users search for with no good result). Closes the supply-side gap vs. PromptBase's creator ecosystem. Quality supply drives demand-side retention.

## Priority 5 — TEAM WORKSPACES (Effort: High)
Shared workspaces, roles (Admin/Editor/Viewer), template sharing workflow, shared billing. Team plans CHF 29-49/user/month. Path into high-margin B2B. One team account (~CHF 200-400/mo) = 20-40 individual PRO subscriptions at same support cost.

## Priority 6 — API ACCESS FOR DEVELOPERS (Effort: Medium)
REST API for programmatic access to own prompts/templates. API key auth, rate limiting per plan. Include in PRO or as add-on. Creates integration lock-in. High-value user segment willing to pay premium.

## Priority 7 — OUTPUT-QUALITY RATING SYSTEM (Effort: High)
After a test-run, users rate the output (1-5 stars). Rating is prompt-version-specific. Shown in discovery view. Solves the market-wide quality inconsistency problem that no competitor has solved.

**Why:** Priorities 1-3 activate the viral growth loop using already-built infrastructure. Priorities 4-5 build the supply-side and B2B revenue layer. Priorities 6-7 create long-term moats.

**How to apply:** When user asks what to build next, always reference this ranked list. Challenge any proposal that skips Priority 1-3 without strong reason — the growth loop gap is the most urgent problem.
