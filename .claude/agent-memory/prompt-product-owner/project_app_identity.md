**App Name:** Vision Notes  
**Tagline:** "Deine persönliche Bibliothek für KI-Prompts. Erstelle, organisiere und entdecke Prompts für alle gängigen KI-Tools – und hole endlich mehr aus deinen KI-Anwendungen heraus."

**Why:** The app solves the core problem that good prompts get lost in chat history, users rewrite the same prompts repeatedly, and there's no structured way to share/version/template prompts for individuals and teams.

**Core differentiators vs. generic tools:**

- Typed form fields on templates (TEXT, TEXTAREA, SELECT, CHECKBOX, etc.) eliminate the blank-page problem
- Version history prevents prompt drift
- Follow-up prompt chains enable guided multi-step AI workflows
- Global reusable fields (define once, use across templates)
- Collection sharing via public token links (no login required for viewers)
- Explore catalog for discovery (publicly accessible, no account needed)

**Primary user segments (from sales materials analysis):**

1. Content creators & marketers (tone-field templates)
2. Developers & prompt engineers (versioning, chaining, composability)
3. Customer support teams (shared collections as response libraries)
4. Freelancers & consultants (per-client collections)
5. Knowledge workers (favorites + categories)
6. AI newcomers (Explore catalog solves blank-page problem)

**How to apply:** Use this when writing feature specs, acceptance criteria, or evaluating new features — always tie back to one of these user segments and the core pain points above.
